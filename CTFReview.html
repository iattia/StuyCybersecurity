Halloween CTF Gauntlet

The ghouls are out! Review your skills with these spooky challenges...

Challenge 1: The Haunted Page 👻

A ghost is haunting this webpage! It left a spooky message hidden in the *spirit* of the page's source code. Find the ghostly comment.

Hint: Ghouls love to hide in the source. Try right-clicking and "View Page Source".

Challenge 2: Witch's Encoded Chant 🧙‍♀️

A witch left this encoded chant in her spellbook. It's written in a common tongue for machines. Decode it from Base64!

ZmxhZ3t0cjFja18wcl90cjM0dH0=

Hint: Take this to your cauldron... or CyberChef. The "From Base64" recipe should do the trick.

Challenge 3: The Ghostly Photograph 📸

We've seen this photo before, but did you check *all* the metadata? Find the name of the "Artist" who captured this image and wrap it in a flag format.

Hint: Use an online EXIF viewer. Find the "Artist" field. The flag is `flag{artist_name_here}`.

Challenge 4: The Graveyard's Keep Out Sign 🪦

The groundskeeper uses `robots.txt` to keep spirits (and search engines) out of certain crypts. Find the secret crypt in this `robots.txt` file.

User-agent: *

Disallow: /cemetery/

Disallow: /tombstones/

Disallow: /secret_crypt_flag{d0_n0t_3nt3r}.html

Hint: One of these "Disallow" paths doesn't look like the others. It looks like a flag!

Challenge 5: Vampire's Secret Note 🧛

A vampire wrote this note, but it's hard to read. It seems like he *rotated* the alphabet. It's a classic Caesar cipher.

synt{v_i4ag_g0_fhpx_l0he_oy00q}

Hint: He's a *classic* vampire, so he uses a *classic* rotation: ROT13. CyberChef can decode this.

Challenge 6: The Stuck Coffin Lid ⚰️

This button opens a coffin full of candy, but the lid is "disabled" by some client-side magic! Can you use your tools to pry it open?

Hint: Right-click the button and "Inspect". Find the `disabled` property in the HTML and delete it. Or, use the Console to run `document.getElementById('flagBtn6').disabled = false;`

Challenge 7: The Headless Horseman's Header 🐴

In many challenges, flags are hidden in the HTTP response headers. A server might send a custom header like `X-Spooky-Flag: flag{...}`. Imagine you used your tools to inspect the network traffic and found this. What's the flag?

Hint: You'd normally use Dev Tools (F12) -> Network tab to find this. For this review, the flag is written on the 'header' in the image!

Challenge 8: The Trick-or-Treat Bag 🍬

This website gave you a piece of "candy" (a cookie) when you arrived. Check your "bag" (browser dev tools) to see what you got!

Candy status: Checking...

Hint: Use dev tools (F12) -> "Application" (Chrome) or "Storage" (Firefox). Find the cookie named `candy_type`. Its value is the flag!

Challenge 9: Monster's Mumble 🧟

We recorded a monster's roar, but it's mostly digital noise. Can you find the one clear message (the flag) hidden inside this data dump?

...x..g.h..a.a..r.g.g.h..%...&..@..x..g.h..a.a..r.g.g.h..%...&..@....x..g.h..a.a..r.g.g.h..%...&..@..flag{1ts_4l1v3_!ts_ALIVE!}.^..&....*..p.n.g.../.e.x.e....x..g.h..a.a..r.g.g.h..%...&..@......

Hint: In a real challenge, you'd use a tool like `strings`. Here, you just need to hunt with your eyes. Look for the `flag{...}` format.

Challenge 10: The Mummy's Curse 🧟‍♂️

This curse is wrapped in many, many layers of encoded linen (Base64). Keep unwrapping (decoding) it in CyberChef until you find the flag!

VmpGWmFXWmdhV0VTWm1NaGNHRXlSbUZrYzNWa2RXa3daVGsxU1pUSlpDTVVPUT09

Hint: This looks like Base64. Try decoding it. What does the result look like? Maybe you need to decode it from Base64 more than once... or five times.

CTF Challenge Gauntlet

Test your new skills with these introductory challenges!

Challenge 1: Web - Hidden in Plain Sight

Developers often leave notes for each other in the code. Find the flag hidden as a comment in this page's HTML source.

Hint: How can you look at the "source" of a webpage? (Try right-clicking).

Challenge 2: Crypto - A Classic Encoding

This flag is encoded in Base64, a very common format for representing data. Decode it to find the real flag.

ZmxhZ3tCYXNlNjRfaXNfZnVuIX0=

Hint: Try using a tool like CyberChef. The name of this encoding has a number in it... a number that's a power of 2.

Challenge 3: Forensics - Data Detective

Digital photos contain hidden "metadata". Download this image and use an online tool to analyze its metadata to find the flag.

Hint: Search for an "online EXIF viewer". The flag is in the 'Copyright Notice' field.

Challenge 4: Web - Don't Be a Robot

Websites use a `robots.txt` file to tell search engines which pages to ignore. Find the flag in this simulated `robots.txt` file content.

User-agent: *

Disallow: /logs/

Disallow: /tmp/

Disallow: /super_secret_admin_page_flag{r0b0ts_4r3_fr13nds}.html

Hint: The 'Disallow' directive tells robots what to avoid. One of these paths looks much more interesting than the others.

Challenge 5: Crypto - A Trip to Ancient Rome

This message was encrypted with a simple Caesar cipher where every letter is shifted. Decode it.

synt{ebg13_vf_punc_pbyyl!}

Hint: A shift of 13 letters (ROT13) is very common. CyberChef has a recipe for it!

Challenge 6: Web - Bypassing the Client

This button is disabled using HTML. Use your browser's developer tools to enable it and get the flag.

Hint: Right-click the button and "Inspect". Find the `disabled` property in the HTML and delete it. Or, use the Console to run `document.getElementById('flagBtn6').disabled = false;`

Challenge 7: Stego - A Conceptual Challenge

Steganography is hiding data inside an image. In a real challenge, you'd download the image and use an online decoder tool (like a "LSB decoder") to find a hidden message. Since this is a simulation, the flag is provided here for you to understand the concept.

Hint: The purpose of this challenge is to teach you what steganography is. No tools are needed this time! Just use the flag from the description.

Challenge 8: Web - What's Cooking?

Websites use cookies to store info in your browser. This page has set a cookie. Find its value in your browser's dev tools!

Cookie status: Checking...

Hint: Use dev tools (F12) -> "Application" (Chrome) or "Storage" (Firefox). Note: If you're opening this as a local file (`file://...`), your browser might block cookies.

Challenge 10: Crypto - Double Trouble

This flag has been put through two layers of encoding/encryption. You'll need to figure out the layers and reverse them.

Wm14aFozdGtNSFZpYkROZllqUnpNelkwWDJZd2NsOTBhRE5mZHpGdWZRbz0=

Hint: This looks like Base64. Try decoding it. What does the result look like? Maybe you need to decode it from Base64 more than once.

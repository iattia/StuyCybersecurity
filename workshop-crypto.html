🔐 Mission Briefing

Your Mission

A secret agent has left you an encrypted message containing crucial intelligence. The message has been encoded using multiple layers of encryption to avoid detection. Your job is to peel back each layer until you reveal the final flag.

Skills You'll Practice

  • Pattern recognition in encoded data
  • Using CyberChef for multi-step decoding
  • Understanding common encoding schemes
  • XOR encryption and decryption
  • Frequency analysis basics

Common Encoding Types

Base64:

Uses A-Z, a-z, 0-9, +, / and = padding

ROT13/Caesar:

Shifted alphabet (A→N, B→O, etc.)

Hexadecimal:

Uses 0-9 and A-F characters only

XOR:

Binary operation with a key

Challenge 2: The Caesar's Digital Scroll 📜

The agent used an ancient cipher combined with modern encoding. First, decode from Base64, then apply the Caesar's favorite rotation.

c3lhZHtubjFwZV9mdXJfcW4zaWF0X200eV9maDRldH0=

Step-by-Step Process:

  1. Identify the first encoding layer
  2. Decode using CyberChef or command line
  3. Analyze the result for patterns
  4. Apply the second decoding method

Tools to Use:

  • CyberChef
  • Command line: base64 -d
  • Online ROT13 decoder
Hint: After Base64 decoding, you should see something that looks like: "flag{...}" but with letters shifted. Try ROT13 (each letter shifted by 13 positions).

🧠 Decoding Strategy

When you see multiple encoding layers, work backwards from the hint:

Agent's Process: Plain Text → ROT13 → Base64 → Hex

Your Process: Hex → Base64 → ROT13 → Plain Text

Hint: The message is all hexadecimal digits (0-9, a-f). First, convert from hex to ASCII. Then you should see Base64. Finally, apply ROT13.

Challenge 4: The XOR Enigma ⚡

The agent used XOR encryption with a single character key. The encrypted message is given in hexadecimal. Your job is to find the key and decrypt the message.

1a021e070a1c0a1b1a0b040c0a1e13001c040c1a041c0c0a1e13001b1a1e1c001c0c1a02

XOR Basics:

  • XOR is reversible: A ⊕ B ⊕ B = A
  • Single-character key means same character used throughout
  • Try common keys: space (0x20), 'A' (0x41), etc.
  • Look for readable English text

CyberChef Recipe:

  1. From Hex
  2. XOR with different single characters
  3. Look for "flag{" at the beginning
  4. Adjust key until readable
Hint: Try XOR with the character 'j' (hex: 0x6A). In CyberChef: From Hex → XOR (key: 'j', format: UTF8) → look for readable text.

🔍 Analysis Questions

1. What characters do you see? (A-Z, a-z, 0-9, special chars?)

2. Does it end with padding (=)?

3. After first decode, what pattern emerges?

4. Keep decoding until you get readable text!

Hint: Starts with Base64 (note the =). Then hex. Then... maybe a simple substitution? Think about what "l33t speak" might look like.

🎓 Cryptography Fundamentals

Encoding vs. Encryption

Encoding (Base64, Hex): Transforms data format, not secret

Encryption (AES, RSA): Secures data with keys

Obfuscation (ROT13): Hides meaning, not secure

Real-World Applications

• Web tokens (JWT) use Base64

• URLs encode special characters

• HTTPS uses multiple encryption layers

• Malware often uses multiple obfuscation

Pro Tips for CTFs

Pattern Recognition: Learn to spot Base64, hex, etc.

Automated Tools: Use scripts for common operations

Frequency Analysis: Common letters appear more often

Context Clues: Challenge names/descriptions give hints
